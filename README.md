# Forma — Astro + Remix 3

Forma is an experimental project for exploring the **Remix 3 component model inside Astro**. A fictional product catalog provides a practical playground for learning how the two work together. It is a learning demo, not a production-ready storefront.

## Demo

The demo will be deployed on **Vercel**.

**Demo URL:** `<add-vercel-deployment-url>`

## Purpose

- Explore how Remix components integrate with Astro, including server rendering and client-side hydration.
- Practice building and composing reusable Remix components.
- Learn how to provide and consume context to share state across components.
- Explore the features of the Remix component model, including events, state updates and component lifecycle.
- Learn how to style Remix components with Tailwind CSS.

Astro handles routing and server endpoints. Remix is used only for its component model, not its backend or router.
